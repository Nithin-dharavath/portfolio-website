     Implementation Plan: Portfolio Landing Page Recreation

     Context

     The goal is to recreate a professional, high-fidelity portfolio landing
     page based on a Figma design (blueprint extracted from a React/Tailwind
     version). The final output must be in Vanilla HTML, CSS, and JavaScript,
     adhering to strict design and architectural standards (no frameworks).

     Implementation Strategy

     1. Project Structure

     - index.html: Single page with semantic sections.
     - static/css/style.css: All styles, including design tokens and responsive
     queries.
     - static/js/main.js: Vanilla JS for interactivity and smooth scrolling.

     2. Design Tokens (CSS Variables)

     Define a :root palette based on the extracted design:
     - --bg-dark: #0f172a (Primary background)
     - --bg-dark-light: #1e293b (Secondary background)
     - --accent: #ff6b6b (Primary accent color)
     - --accent-dark: #ff5252 (Accent hover/gradient)
     - --text-main: #ffffff
     - --text-muted: #9ca3af (Gray-400)
     - --border-color: rgba(255, 255, 255, 0.1)
     - --glass-bg: rgba(255, 255, 255, 0.05)
     - --radius-lg: 1.5rem (24px)
     - --radius-md: 0.75rem (12px)

     3. Section Breakdown

     Hero Section

     - Navigation: Fixed top bar with backdrop-blur and semi-transparent
     background.
     - Background: Gradient from(#0f172a) via(#1e293b) to(#0f172a) with
     animated, blurred orbital glows (using CSS animations).
     - Content:
       - Welcome badge (uppercase, bg-accent/10, border-accent/20).
       - Typographic hierarchy: H1 (Hello.), Subtitle (I'm Nithin), H2 (Fresher
     Backend Developer), Description.
       - CTAs: Primary (Gradient button) and Secondary (Glass border button).
       - Tech Stack: A flex-wrap container of glass-styled pills.
     - Visuals: A centered profile card with a developer emoji, "Available for
     work" pulse indicator, and floating stats cards (Years Exp, Projects) with
     bounce animations.
     - Scroll Indicator: Animated mouse/scroll icon at the bottom center.

     Services Section ("What I Do")

     - Layout: Grid layout (2 columns on desktop).
     - Cards: Glass-morphism cards with:
       - Hover state: Border color change to accent, slight scale-up, and a
     subtle inner gradient.
       - Content: Icon (emoji), Title, and Description.
     - Services to include: Website Development, App Development, Performance
     Optimization.

     About Section ("About Me")

     - Layout: Grid layout (2 columns on desktop, reversed from services).
     - Content:
       - Multi-paragraph description.
       - Stats grid: 3 cards with gradient text values.
       - Skill Bars: Custom progress bars with labels and percentage indicators.

     Projects Section ("Featured Projects")

     - Layout: Mix of large featured cards and smaller grid cards.
     - Project Cards:
       - Glass background with accent border on hover.
       - Integration of tech badges (small pills).
       - Action buttons: "Live Demo" (Gradient) and "View Code" (Bordered).
       - Preview areas: Gradient boxes with representative emojis/icons.
     - GitHub Link: Centered link with an SVG GitHub icon.

     Contact Section

     - Layout: Split grid (Text/Info vs. Form).
     - Contact Info: List of items (Email, Phone, Location) in glass containers.
     - Contact Form:
       - Glass-morphism container.
       - Inputs: Dark background, subtle border, accent color focus ring.
       - Submit Button: Full-width gradient button.

     Footer

     - Layout: 4-column grid for links and branding.
     - Elements: Logo, Short bio, Social links (SVG icons), Quick links, and
     Bottom copyright bar.

     4. Responsive Design

     - Desktop (1440px+): Full grid layouts, centered containers.
     - Tablet (768px-1439px): Adjust grid columns (usually to 1 or 2), reduce
     font sizes for headers.
     - Mobile (320px-767px): Single column layout, stacked elements, adjusted
     padding/margins, and simplified navigation (hamburger menu or simple list).

     5. Technical Details & Interactivity

     - Smooth Scrolling: Implementation of scroll-behavior: smooth in CSS and JS
     fallback for navigation links.
     - Glassmorphism: Extensive use of backdrop-filter: blur() and rgba
     backgrounds.
     - Animations:
       - Keyframes for orbital glows (pulse, float).
       - Transition transforms for hover effects on all cards and buttons.
       - Entrance animations (optional but recommended for "premium" feel).

     Verification Plan

     - [ ] Visual Audit: Compare every section (spacing, colors, fonts) against
     the App.tsx blueprint.
     - [ ] Responsiveness: Test at 320px, 768px, and 1440px widths.
     - [ ] Accessibility: Verify semantic tags (nav, section, footer, h1-h3) and
     contrast.
     - [ ] Performance: Check for redundant CSS and ensure GPU acceleration for
     animations (will-change, transform).
     - [ ] Interactivity: Ensure all links, buttons, and form fields have clear
     hover/focus states.
